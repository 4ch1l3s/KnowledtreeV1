🚀 Hướng dẫn chạy dự án
Bước 1 — Mở Terminal và chạy file setup.bat

Trên Windows, mở CMD hoặc PowerShell ngay tại thư mục dự án.

Sau đó chạy lệnh:

setup.bat


File setup.bat sẽ tự động:

Cài môi trường cần thiết

Cài các thư viện Python

Chuẩn bị mọi thứ để dự án chạy được

Bước 2 — Chạy webcam

Sau khi setup xong, bạn có thể chạy chương trình webcam bằng:

python webcam.py
